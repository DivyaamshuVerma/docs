##### **Deleting Links:**



Delete association statement is used to delete an association between two object instancecs.

For example, if you want to delete a Coverage from under General Liability instance, we can use

the delete association statement to delete the existing coverage.



Syntax of delete association is,



del <fieldReference>



**Example:**



del coverage\[Code="PREMOPS"]



|Keyword|Description|
|-|-|
|del|deletes an object|
|del association|deletes the link between the two objects OR<br /><br />deletes the link between an object model and an object (TBC)<br /><br />(in both cases the object is intact but is only hidden from accessing the data)|



**Example:**



**Example 1**



App Name -ﾠDeleteObjectAssociation1



If you want to delete the Driver object along with the link between Vehicle and Driver, you can use the 'del' statement without association keyword.



def x as MasterModel:Root

del association x.Driver



**Example 2**



Delete association statement is used to delete an association between two object instances. For example, if you want to delete a Coverage from under vehicle instance, we can use the delete association statement to delete the existing coverage.ﾠSyntax:-



del {association}ﾠ<fieldReference>



**Example 3**



Example:ﾠApp Name -ﾠDeleteObjectAssociation1



Considering you have access to the Vehicle instance, you can select a specific coverage object instance and delete link between Vehicleﾠand Driver using delete statement. Delete association expression just delete the link, but keep the coverage object in database.



def x as MasterModel:Root
